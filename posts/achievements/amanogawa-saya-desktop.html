天之川沙夜 · 桌面陪伴

2026年7月

以《仰望夜空的星辰》角色天之川沙夜为形象的 Windows 桌面陪伴应用：VPet 风格全身桌宠，默认以全身立绘常驻桌面，可拖动、托盘驻留，支持点击互动、聊天与夸奖，并带基础星轨亲密度（0–100 与对应称谓）。

全身动态：以姿势帧序列切换实现动作（类似 VPet 精灵帧动画），脚底为锚点并带轻微 CSS 补间——待机呼吸、左右张望、原地小跑、坐下、伸懒腰、挥手、点击弹跳、害羞、庆祝、被拖动拎起等；固定冬制服形象，动作由 assets/animations/<动作>/ 下 PNG 帧驱动，可用 Python 脚本重新打包帧资源。

交互与窗口：拖动移动窗口（拖动时进入被拎起姿势）；单击展开快捷栏（聊聊 / 夸奖 / 面板）并弹跳回应；三档窗口（紧凑全身 → 快捷栏 → 面板）锚点缩放不乱跳；Esc 收起面板或在紧凑模式隐藏到托盘。定位为纯陪伴，不含计时、喝水提醒等效率工具。

技术栈：Electron（v0.4.0）；本地运行 npm install 后 npm start。角色版权归属原作相关权利方，个人向原型，勿作商业用途。
